## 📌 Overview
This repository contains an end-to-end Machine Learning solution designed to predict the likelihood of **Chronic Kidney Disease (CKD)** in patients based on key clinical parameters (such as Blood Pressure, Specific Gravity, Albumin levels, and Blood Sugar).

The goal of this project is to assist healthcare professionals with an automated, web-based decision-support tool for early risk detection.

---

## ✨ Key Features
* **Machine Learning Engine:** Trained using **Random Forest Classifier** achieving high classification accuracy.
* **Interactive UI:** Built with **Streamlit** to offer a responsive, user-friendly clinical dashboard.
* **Real-time Risk Assessment:** Instant predictions generated based on user input parameters.
* **Cloud Deployed:** Hosted live on Streamlit Community Cloud for seamless public access.
